# 电脑端

这是运行在电脑上的本地服务，接收小程序上传的文件，并提供一个本地网页作为控制台。

当前版本支持：

- 运行中总览：服务状态、小程序在线状态、今日接收、待取文件
- 地址自动发现：mDNS 广播 `_http._tcp.`，安卓小程序可自动找到电脑，无需手填 IP
- 局域网地址列表：自动列出可访问的 `http://IP:端口`，优先 WLAN/以太网并过滤虚拟网卡
- 设备列表：显示最近心跳、在线状态、上传数
- 文件双向传输：
  - 小程序 → 电脑：小程序从微信会话选文件上传，网页可下载、删除
  - 电脑 → 小程序：网页「发送到小程序」拖拽/批量选本机文件，复制进待取区；小程序在「传输 → 从电脑取」里接收（转发到聊天或预览）
  - 同名同内容判重、同名不同内容另存为 `名字 (2).ext`，不覆盖已有文件
- 接收与待取文件都保留 30 天：启动时和每 6 小时自动清理超期文件，也可在网页/小程序手动清理
- 发票台账：CSV 文件长期保存、列表展示、搜索筛选、导入导出、重复高亮
- 手动录入：台账页「新增发票」，批次固定写「手动录入」，保存后立刻显示重复标记
- 小程序收票：扫码后一键发送至电脑台账，发送前查重并让用户决定重复票去留
- 重复处理：按「发票代码+号码」判重，重复组抽屉对比，用户自行删除
- 补录：表格行「补录」按钮，或直接点报销人单元格行内改
- 按录入时间清理：预览命中数量后确认删除，清理前自动备份
- 批次与录入时间：每次导入自动生成批次，每行记录录入时间
- 自动备份：每次写入台账前备份上一版到 `backup/`

## 启动

在 `desktop/` 目录下执行：

```bash
go run .
```

启动日志会打印局域网地址，例如：

```text
手机访问: http://192.168.1.20:8765
```

自定义监听地址、目录和保留天数：

```bash
go run . -addr :9000 -data ./data -keep-days 30
```

或设置环境变量：

```bash
INVOICE_ADDR=:9000
INVOICE_DATA_DIR=./data
INVOICE_KEEP_DAYS=30
```

`-keep-days` 默认 30，设为 0 或负数关闭自动清理（仍可手动清理）。

## 小程序如何连接

1. 电脑端启动后，打开 `http://localhost:8765`
2. 安卓手机连同一 WiFi，小程序进入「设置 → 桌面端连接」，点「自动搜索电脑」
3. 找到后自动保存地址并开始心跳；找不到时可在电脑网页复制地址手动填写
4. iOS 微信 7.0.18 起不支持 mDNS，请手动填写地址
5. 小程序打开时每 20 秒上报一次心跳；启动、扫码换地址、从后台回到前台时都会立刻补报一拍，不用等周期
6. 桌面端显示「小程序在线」即表示连接成功（网页未连接时每 2 秒刷一次状态，连上后 5 秒）

判定窗口为 45 秒；超过 45 秒没有心跳会显示为离线。首次启动未配置地址时会自动搜索一次，失败后 10 分钟内不再重试。

## 发票台账

网页顶部切到「发票台账」：

- 搜索：全局关键词、发票号码、报销人、批次、日期范围、金额范围
- 筛选：仅看重复、仅看待补录（报销人为空）
- 排序：录入时间（默认）/ 发票号码 / 开票日期 / 报销人
- 导入：先预览新增/重复/无效数量，确认后写入
- 新增：点「新增发票」手填一条，批次记为「手动录入」；号码必填，重复会当场标记
- 导出：全部、当前筛选、勾选记录（「仅看重复」筛选也能正确导出，不会再出空表）
- 删除：单张删除或勾选批量删除
- 补录：点行末「补录」编辑字段，或直接点报销人单元格行内修改；批次和录入时间保持不变
- 清理：按电脑端录入时间区间先预览再删除，只影响电脑台账
- 重复：列表红色标记，点「查看重复组」逐组对比删除

小程序端的台账页读的就是这里的接口（`GET /api/invoices`），只读、不落库，
增删改一律在网页做；小程序的「导出」也是下载这里的 CSV 再转发到微信。

CSV 列（8 列）：

```text
发票号码,发票代码,票种,开票日期,价税合计,报销人,录入批次,录入时间
```

按表头名读取，兼容旧版 12/14 列 CSV。判重键是「发票代码+号码」，金额和开票日期不参与。
重复记录会写入台账并高亮，由用户自行删除，不自动删除。

### 小程序扫码结果写入台账

小程序在单张导入、批量导入或批量扫码结束后，会询问「是否发送到电脑台账」。

1. 小程序先请求 `POST /api/invoices/check`，把本次发票的「代码+号码」发给电脑查重。
2. 若发现重复，弹窗显示号码、金额和日期，用户选择「仍然发送」或「跳过重复」。
3. 确认后请求 `POST /api/invoices`，电脑端按批次写入 `invoices.csv`。
4. 扫码草稿只有号码、日期和价税合计，报销人留空，电脑台账列表会标记「待补录」，可在网页直接点单元格补。

单批最多 200 张；超过时小程序会先弹提示，由用户选择只发前 200 张或取消。写入前自动备份上一版台账。发送失败不会清空手机本地记录，可稍后重试。

## 接收文件的保留与清理

`incoming/` 里放的是小程序传上来的原件，只用于中转，不是长期存储：

- 默认保留 30 天。服务启动时清一次，之后每 6 小时清一次，超期文件连同索引记录一起删除。
- 只按 `uploaded_at` 判断；时间解析不出来的记录一律不删，宁可留着也不误删。
- 手动清理走两个接口，都是先预览再确认：
  - `POST /api/incoming/purge`：`{"days":30,"confirm":false}` 只返回命中数量，`confirm:true` 才真删。
  - `DELETE /api/incoming`：`{"ids":["..."]}` 删指定文件，`{"all":true}` 清空。
- 每次清理会写一条事件到 `registry.json`，可在网页事件列表里看到删了多少个。

小程序端「传输中心 → 我的上传」也有删除和「清理超 30 天」，但那里删的只是手机本地发送历史，**不动电脑磁盘上的文件**；要腾电脑空间得删「电脑已收」。

## 数据目录

```text
desktop/data/
├── incoming/     小程序上传到电脑的文件
├── outgoing/     电脑提供给小程序下载的文件
├── backup/       发票台账历史备份
├── invoices.csv  发票台账主文件
├── index.json    上传记录索引
└── registry.json 设备与事件记录
```

把要发给小程序的文件放进 `outgoing/` 即可，或在网页「发送到小程序」里选文件（等价，都是复制）。

待取副本到期会自动清理，但**你电脑上原位置的文件不受影响**——这里存的是副本。

## 当前限制

- 单文件最大 20MB
- 接收文件按 30 天清理，不按容量限制；一次传几千张仍会占满磁盘
- 发票 CSV 只接受 UTF-8 编码，Excel 请另存为「CSV UTF-8」
- 没有 token 验证，只能在可信局域网内自用
- 地址自动发现依赖 mDNS（UDP 5353），Windows 首次可能需要在防火墙放行；iOS 微信不支持 mDNS
- 小程序扫码草稿字段有限，写入台账后仍需人工补录销方与税额

接口协议见 `shared/protocol.md`。
