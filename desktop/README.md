# 电脑端

这是运行在电脑上的本地服务，接收小程序上传的文件，并提供一个本地网页作为控制台。

当前版本支持：

- 运行中总览：服务状态、小程序在线状态、今日接收、电脑待取
- 局域网地址列表：自动列出可访问的 `http://IP:端口`，优先 WLAN/以太网并过滤虚拟网卡
- 设备列表：显示最近心跳、在线状态、上传数
- 上传文件：网页拖拽/批量选择，小程序 multipart 上传
- 文件列表：搜索、下载、删除
- 最近事件：上传、删除事件记录
- 快捷连接：设置页保存电脑地址后，小程序自动上报心跳

## 启动

在 `desktop/` 目录下执行：

```bash
go run .
```

启动日志会打印局域网地址，例如：

```text
手机访问: http://192.168.1.20:8765
```

自定义监听地址和目录：

```bash
go run . -addr :9000 -data ./data
```

或设置环境变量：

```bash
INVOICE_ADDR=:9000
INVOICE_DATA_DIR=./data
```

## 小程序如何连接

1. 电脑端启动后，打开 `http://localhost:8765`
2. 在「连接小程序」卡片复制局域网地址
3. 小程序进入「设置 → 桌面端连接」
4. 填入地址，点「保存地址」或「测试连接」
5. 小程序打开时每 20 秒上报一次心跳
6. 桌面端显示「小程序在线」即表示连接成功

判定窗口为 45 秒；超过 45 秒没有心跳会显示为离线。

## 数据目录

```text
desktop/data/
├── incoming/     小程序上传到电脑的文件
├── outgoing/     电脑提供给小程序下载的文件
├── index.json    上传记录索引
└── registry.json 设备与事件记录
```

把要发给小程序的文件放进 `outgoing/` 即可。

## 测试

```bash
go test ./...
```

## 当前限制

- 单文件最大 20MB
- 没有 token 验证，只能在可信局域网内自用
- 不做自动发现和二维码，地址可手动复制

接口协议见 `shared/protocol.md`。
