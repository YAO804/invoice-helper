# 电脑端

这里放运行在电脑上的本地服务，负责接收小程序上传的文件、提供本地网页和可下载文件列表。

规划结构：

```text
desktop/
├── main.go              入口，后续创建
├── go.mod               Go module，后续创建
├── internal/
│   ├── api/             HTTP 接口
│   ├── files/           文件保存、列表、去重、清理
│   ├── config/          本机配置
│   └── discover/        局域网发现
├── web/                 本地网页静态文件
└── data/                运行时数据，不提交 Git
```

当前阶段只建立目录约定，尚未写入电脑端代码。
