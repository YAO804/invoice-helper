# 电脑端

这是运行在电脑上的本地服务，接收小程序上传的文件，并提供一个本地网页作为控制台。

当前版本支持：

- 运行中总览：服务状态、小程序在线状态、今日接收、电脑待取
- 局域网地址列表：自动列出可访问的 `http://IP:端口`，优先 WLAN/以太网并过滤虚拟网卡
- 设备列表：显示最近心跳、在线状态、上传数
- 文件传输：网页拖拽/批量选择上传，小程序 multipart 上传，下载和删除
- 发票台账：CSV 文件长期保存、列表展示、搜索筛选、导入导出、重复高亮
- 重复处理：按发票号码判重，重复组抽屉对比，用户自行删除
- 批次与录入时间：每次导入自动生成批次，每行记录录入时间
- 自动备份：每次写入台账前备份上一版到 `backup/`

## 启动

在 `desktop/` 目录下执行：

```bash
go run .
```

启动日志会打印局域网地址，例如：

```text
手机访问: http://192.168.1.20:8765
```

自定义监听地址和目录：

```bash
go run . -addr :9000 -data ./data
```

或设置环境变量：

```bash
INVOICE_ADDR=:9000
INVOICE_DATA_DIR=./data
```

## 小程序如何连接

1. 电脑端启动后，打开 `http://localhost:8765`
2. 在「连接小程序」卡片复制局域网地址
3. 小程序进入「设置 → 桌面端连接」
4. 填入地址，点「保存地址」或「测试连接」
5. 小程序打开时每 20 秒上报一次心跳
6. 桌面端显示「小程序在线」即表示连接成功

判定窗口为 45 秒；超过 45 秒没有心跳会显示为离线。

## 发票台账

网页顶部切到「发票台账」：

- 搜索：全局关键词、发票号码、销方、批次、日期范围、金额范围
- 筛选：仅看重复、仅看待补录
- 导入：先预览新增/重复/无效数量，确认后写入
- 导出：全部、当前筛选、勾选记录
- 删除：单张删除或勾选批量删除
- 重复：列表红色标记，点「查看重复组」逐组对比删除

CSV 列：

```text
发票号码,发票代码,票种,开票日期,销方名称,销方税号,买方名称,买方税号,
不含税金额,税额,价税合计,税率,录入批次,录入时间
```

兼容旧版 12 列 CSV。重复记录会写入台账并高亮，由用户自行删除，不自动删除。

## 数据目录

```text
desktop/data/
├── incoming/     小程序上传到电脑的文件
├── outgoing/     电脑提供给小程序下载的文件
├── backup/       发票台账历史备份
├── invoices.csv  发票台账主文件
├── index.json    上传记录索引
└── registry.json 设备与事件记录
```

把要发给小程序的文件放进 `outgoing/` 即可。

## 测试

```bash
go test ./...
```

## 当前限制

- 单文件最大 20MB
- 发票 CSV 只接受 UTF-8 编码，Excel 请另存为「CSV UTF-8」
- 没有 token 验证，只能在可信局域网内自用
- 不做自动发现和二维码，地址可手动复制
- 小程序扫码结果尚未自动写入台账，留待下一步

接口协议见 `shared/protocol.md`。
